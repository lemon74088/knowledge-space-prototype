# Knowledge Space · 個人知識整理原型 V0.1

中醫知識整理 App 的單檔 HTML 原型：iPhone 優先、資料真實存在本機、繁簡互搜。整份介面只用一張 `index.html`，沒有建置流程、沒有 CDN 依賴。

## 線上預覽

GitHub Pages：`https://lemon74088.github.io/knowledge-space-prototype/`

## 功能

- **六大核心頁面**：首頁總覽、全域搜尋、筆記與收集匣、資料庫、知識圖譜、研究中心。
- **區塊編輯器**：標題／段落／引用／表格／HTML 五種區塊，引用與 HTML 可獨立設陰影；支援 HTML 直接寫入並渲染。
- **模板**：每個區塊都能「存模板」，也能把整篇所有區塊存成模板；模板清單標示類型與摘要，插入後仍可改。
- **研究中心**：平台名稱、說明與各研究線（名稱／說明／計數類型）皆可編輯、新增、刪除，資料存本機。
- **分類**：分類可切換，包含「未分類」。
- **刪除**：編輯器可單篇刪除；筆記與資料庫頁可進入選取模式批量刪除（全選／已選 N 筆），刪除後 12 秒內可復原。
- **手機頁首**：往下捲自動隱藏、往上捲立刻回來，最頂端必定顯示。
- **桌面側欄**：可收合到只留圖示，主內容同步變寬，狀態會記住。
- **繁簡互搜**：內建約 180 組單字與地區用語對照，逐字建立位置對映以便高亮回跳。

## 資料存放

- 筆記與設定寫入 IndexedDB（`knowledge_space_v01`），關掉頁面重開仍在；不支援時自動降級 localStorage。
- **必須用 http(s) 開啟**（GitHub Pages 沒問題）。直接雙擊 `file://` 開啟時瀏覽器不給 IndexedDB，會落到降級模式。
- 「設定與備份」可匯出／匯入 JSON，包含筆記、模板、研究線與設定。
